## 💡 4. Glosario Técnico & Cheat Sheet para la Entrevista

* **Vue 3 Composition API:** Paradigma introducido en Vue 3 que permite organizar la lógica de los componentes por características funcionales mediante funciones importadas (`ref`, `reactive`, `computed`, `watch`) dentro de un bloque `<script setup>`, resolviendo las limitaciones de reutilización de la Options API tradicional.
* **`ref` vs `reactive`:** `ref()` se usa para envolver tipos primitivos (o cualquier dato) devolviendo un objeto reactivo con propiedad `.value`; `reactive()` envuelve directamente objetos o arrays y mantiene la reactividad de sus propiedades internas.
* **Despliegues en S3 y Cloud:** Práctica estándar de frontend para Single Page Applications (SPA), donde el bundle estático compilado (`dist/` o `build/`) se aloja en un bucket de S3 configurado como sitio estático o distribuido globalmente mediante CDN (CloudFront / Cloudflare).
* **Flexbox vs CSS Grid:** Flexbox está optimizado para layouts unidimensionales (filas o columnas, alineación dinámica de items); CSS Grid está diseñado para layouts bidimensionales (filas y columnas simultáneas, estructuras maestras de página).
* **Idempotencia y Manejo de Estados en APIs REST:** Práctica de frontend que contempla y maneja adecuadamente los 4 estados de una petición asíncrona: *idle*, *loading* (spinners/skeletons), *success* (renderizado de data normalizada) y *error* (mensajes contextuales y reintentos sin efectos colaterales).
