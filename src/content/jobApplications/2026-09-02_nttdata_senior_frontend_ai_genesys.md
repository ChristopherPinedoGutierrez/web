### Genesys Cloud SDKs & Integración Web (CTI)
* **Definición en la vacante:** Librerías oficiales en JavaScript para embeber controles de llamadas, chat omnicanal y gestión de interacciones dentro de una aplicación web corporativa.
* **Tu defensa:** *Consumo los SDKs de Genesys Cloud en React estructurando Custom Hooks desacoplados que gestionan el ciclo de vida de la sesión, eventos de audio y streaming de mensajes sin acoplar la UI a la lógica del proveedor.*

### WebSockets & Streaming de Eventos en React
* **Definición en la vacante:** Protocolo de comunicación bidireccional permanente sobre una única conexión TCP, ideal para chats en vivo y respuestas token a token de IA.
* **Tu defensa:** *Implemento conexiones WebSocket resilientes con manejo de reconexiones automáticas, tipado estricto de eventos y sincronización de estado en React para interfaces en tiempo real.*

### Google Cloud Run & Firebase en Arquitecturas Frontend
* **Definición en la vacante:** Servicios de Google Cloud para hospedar contenedores serverless ligeros y servicios de autenticación/base de datos en tiempo real.
* **Tu defensa:** *Despliego aplicaciones y microservicios desacoplados en Cloud Run mediante contenedores Docker multi-stage optimizados, integrando autenticación segura y baja latencia.*
