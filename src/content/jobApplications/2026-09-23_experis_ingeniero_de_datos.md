## 🛠️ 4. Glosario Técnico & Cheat Sheet para la Entrevista

* **Data Warehouse vs Data Lake:** En el DWH estructuramos datos procesados y limpios para BI (esquemas estrella/copo de nieve); en el Data Lake almacenamos datos crudos multiformato antes de su transformación.
* **SQL Server / Consultas complejas:** Uso de CTEs (Common Table Expressions), funciones de ventana (Window Functions: `ROW_NUMBER()`, `RANK()`), optimización de índices para acelerar reportes pesados.
* **GCP / BigQuery:** Aunque la infraestructura es cloud serverless, el motor analítico de BigQuery opera sobre ANSI SQL optimizado para queries distribuidas sobre grandes volúmenes.
* **Integración con IA:** Capacidad de preparar y sanitizar datos para entrenar modelos o alimentar sistemas RAG / APIs de modelos de lenguaje.
