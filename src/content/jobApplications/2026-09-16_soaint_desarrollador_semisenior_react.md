## 💡 4. Glosario Técnico & Cheat Sheet para la Entrevista (SOAINT Edition)

* **Single Page Application (SPA):** Aplicación web que carga un único documento HTML y actualiza dinámicamente el contenido mediante JavaScript según la navegación del usuario (React Router), sin recargar la página completa.
* **Componentes Controlados vs No Controlados:** En React, un componente controlado tiene su valor administrado por el estado del framework (`value` + `onChange`), mientras que el no controlado delega el valor al DOM nativo (usando `useRef` o librerías como React Hook Form para mejor rendimiento).
* **Flujos Multi-paso (Wizard Pattern):** Patrón de diseño UI donde un proceso complejo (ej. registro o contratación) se divide en pasos secuenciales validados independientemente, sincronizando un estado global temporal antes de enviar el payload final a la API.
* **Zustand vs Redux Toolkit:** Zustand ofrece un store basado en hooks sin necesidad de envolver la aplicación en `Context Providers`, reduciendo el boilerplate y evitando renderizados masivos gracias a selectores atómicos.
* **HTML Semántico y Accesibilidad (a11y):** Uso de etiquetas estructurales correctas (`<main>`, `<nav>`, `<section>`, `<article>`, `<button>`) y atributos ARIA para permitir navegación por teclado y lectores de pantalla.
* **Code Review & Pull Requests:** Práctica colaborativa en Git donde los cambios propuestos son inspeccionados por pares antes del merge para asegurar estándares de codificación, cobertura de pruebas y detección temprana de regresiones.
