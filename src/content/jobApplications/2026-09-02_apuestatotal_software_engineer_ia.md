## 📚 4. Glosario Técnico & Defensa de Stack (Apuesta Total AI Coding Edition)

### AGENTS.md / CLAUDE.md (Memoria de Proyecto & Rulebook)
* **Definición en la vacante:** Archivo raíz versionado en Git que define las reglas de arquitectura, convenciones de código y límites operativos que los agentes deben respetar obligatoriamente.
* **Tu defensa:** *Implemento `AGENTS.md` como el contrato de gobernanza de mis repositorios, asegurando que cualquier agente o subagente opere bajo estándares de código limpios, reglas de testing y flujos de trabajo predecibles.*

### Skills (SKILL.md) vs. Subagentes vs. MCP
* **Definición en la vacante:** Comprensión clara de los mecanismos de extensión agéntica.
* **Tu defensa:** *Uso `Skills` (SKILL.md) para empaquetar conocimiento procedural y scripts especializados que se cargan según el contexto; `Subagentes` para aislar la ejecución de tareas complejas con su propio contexto y herramientas; y `MCP` como el protocolo estándar para conectar a los agentes con APIs externas y bases de datos.*

### Plan Mode & Diffs Pequeños y Auditables
* **Definición en la vacante:** Metodología de trabajo donde el ingeniero valida el diseño técnico antes de permitir que la IA modifique código.
* **Tu defensa:** *Aplico siempre una fase previa de planificación técnica (`specs/`) y descompongo las tareas para que cada cambio en el repositorio genere diffs pequeños, fáciles de auditar en Code Review y libres de regresiones.*
