## 💡 4. Glosario Técnico & Cheat Sheet para la Entrevista

* **OpenAPI / Swagger:** Estándar para describir contratos de APIs REST de forma legible para humanos y máquinas, permitiendo generar SDKs, mocks y validaciones automáticas.
* **OAuth2 / Bearer Tokens:** Protocolo de autorización para delegar acceso seguro a servicios sin exponer credenciales, implementando flujos como *Client Credentials* para comunicación entre microservicios bancarios.
* **API Gateway (ej. Azure APIM):** Punto de entrada único que gestiona enrutamiento, autenticación, limitación de tasa (rate limiting), telemetría y políticas de seguridad para los endpoints del banco.
* **Idempotencia:** Propiedad de una API donde una solicitud repetida produce el mismo resultado sin efectos colaterales no deseados (crucial en transacciones bancarias y reintentos de webhooks).
* **Azure OpenAI Service:** Servicio en la nube de Microsoft que expone modelos LLM dentro de un perímetro de red privado con gobernanza de datos y seguridad empresarial.
